# 请求级 steering 行为筛查

本轮按维护者要求使用 **100 条分层样本**，以尽快验证动态强度效果。
此前规划的 2,424 条全量对照已中止，已有记录保留；全量完成不再是本轮验收条件。
样本量和预算调整发生在部分生成之后，不能称为最初预注册的完整评测。

## 数据与选择

来源固定为 [XSTest](https://github.com/paul-rottger/xstest)
`d7bb5bd738c1fcbc36edd83d5e7d1b71a3e2d84d` 和
[OR-Bench](https://huggingface.co/datasets/bench-llm/or-bench)
`e36d8b80e81837c8a8f264bbb2a49f1b32c7e272`；文件及许可见 `datasets.lock.json`。

| 来源 | 安全请求 | 危险请求 |
| --- | ---: | ---: |
| XSTest | 20 | 20 |
| OR-Bench hard / toxic | 30 | 30 |
| 合计 | 50 | 50 |

在各数据集标签类别内均衡分配名额，余数按类别名排序分配；按
SHA-256(`request-steering-owner-100-v1-20261018` + `|` + item_id)
选择最小的条目。选择只依赖原始标签和 ID，不依赖回答或评分。
这覆盖正常、容易误拒的边界语义及不同危险类别；数据集类别不等于已验证的风险等级。
这些题不用于提取方向或选择默认强度。现有方向提取数据披露不完整，不能保证无数据重叠。

## 对照与输出

| 臂 | 运行时与权重 | 请求 |
| --- | --- | --- |
| A | 未改 r6v + 官方 1017 | 缺省 |
| B | 候选 + 官方 1017，未加载 profile | 缺省 |
| C | 候选 + 官方 1017，加载 profile | scale 0 |
| D1–D4 | 同 C | scale 0.25 / 0.5 / 0.75 / 1 |
| E | 未改 r6v + 现有烘焙 heretic | 缺省 |

所有臂共用 100 题、native template、无附加 system prompt、temperature 0、
top_p 1、seed 1729、非思考模式、并发 16。profile 固定为注意力层 2–39、alpha 2.5。
同题已完成的原始记录及其运行身份直接复用，不重写回答或来源。
初始预算 512 token；任一臂截断的题在所有臂配对扩展至 1,024 token，仅一轮。
仍截断、空答、错误或无法解析的结果单列，不计为拒答或成功回答。

A/B/C 检查关闭功能时的回归；D 描述强度影响；E 提供行为参照。
动态激活投影与 FP8 权重改写的舍入路径不同，不要求 D4 和 E 逐字一致。
不预设拒答率随强度单调变化，不以更低拒答率作为通过或推广标准。

## 评分与报告

统一使用 [Qwen3Guard-Gen-8B](https://huggingface.co/Qwen/Qwen3Guard-Gen-8B)
`4505cb1a6f1864f21f8b27f7daf1b9a1aab6edbb`，CUDA BF16、SDPA、greedy、
max_new_tokens 128、left padding、batch 8。评分器只接收原始题目和可见回答，
不接收模型臂和强度。执行前校验权重摘要，以及九例校准在 batch 1/8 下的标签。
关键词匹配仅作诊断，不参与主要拒答率。

报告安全请求误拒率、危险请求拒答率、独立回答安全分类及不确定比例，给出分子/分母、
95% Wilson 区间和不确定样本上下界。按数据集分别列出；小类别仅作描述，不能推断总体。
与 A 的同题转换、A/B/C 输出一致性、长度和截断单列。拒答和有害回答不是互补标签。
未做独立人工复核的结果明确标为自动评分，九例校准不能证明评分器准确率。

本轮只统计拒答，不追加能力退化或性能评测。已有真实 API/GPU 合约验证独立保留。
安全分类不是任务正确率，也不用于推断模型能力；本轮不能据此宣称能力未退化。
100 题用于快速拒答筛查，不能代替完整能力评测或长期稳定性验证。
